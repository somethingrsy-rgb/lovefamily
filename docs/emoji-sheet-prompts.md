# 우리집 이모지 시트 프롬프트 (한 장에 12개씩, 총 10장)

이모지 116종을 **이미지 한 장에 12개씩** 한 번에 만들도록 합쳤어요. 시트 하나의 회색 코드 블록을 통째로 복사해 붙여 넣으면 됩니다.

## 사용 방법
1. 시트 1번부터 코드 블록을 통째로 복사해 이미지 도구(ChatGPT·Gemini 등)에 붙여 넣습니다.
2. 결과가 **4칸 × 3줄 격자, 칸 크기 동일, 흰 배경**인지 확인하세요. 줄 수나 개수가 틀리면 "make exactly 4 columns and 3 rows with 12 icons" 한 줄만 덧붙여 다시 만들면 됩니다.
3. 시트 이미지를 **파일 이름 그대로**(`sheet-01.png` …) 채팅에 보내 주세요. 칸을 잘라 투명 배경 처리하고 각 이모지 자리에 연결해 드립니다.
4. 한 번에 다 만들 필요 없이, 한 장씩 만들어 보내 주셔도 됩니다.

> 한 장에 너무 많이 넣으면 도구가 그림을 흐리게 그립니다. 그래서 12개로 정했어요. 도구가 16개도 선명하게 그리면 알려 주세요. 다시 합쳐 드릴게요.
