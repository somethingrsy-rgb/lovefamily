# 우리집 가족 대시보드

거실 iPad(가로)와 어른 휴대폰에서 쓰는 한국어 홈 화면 설치형 웹앱(PWA)입니다.
루틴 체크 → 어른 도장 승인(첫 승인 1건만 확정) → 30개 도장 보상 5,000원 → 돼지 저금통 장부, 사고 싶은 것/저축 미션, 엄마·아빠 상태, 공용 사진 알림장, 개인 메시지, 실시간 팝업과 휴대폰 푸시까지 구현했습니다.

## 구성 (선택 사항)
- 서버: Node 22+ (내장 `node:sqlite`) 단일 프로세스, 의존성은 `web-push` 하나. DB와 사진은 `DATA_DIR`(기본 `./data`)에 저장 — 가족 전용 비공개, 사진은 로그인·권한 확인 후에만 전송.
- 화면: 빌드 단계 없는 바닐라 JS PWA(`public/`). 실시간은 SSE(내용 없는 변경 신호 + 권한 검증 API 재조회).
- 인증: 어른 각자 계정(아이디/비밀번호), 가족 코드·초대 링크로 연결. 거실 기기는 "공용 기기 모드"로 로그인하고, 승인·잔액 정정 등 어른 동작은 어른 선택+비밀번호 재인증(10분). 아이별 4자리 비밀번호(선택)로 서로의 저금통·메시지 보호.
- 금액은 원 단위 정수, 날짜는 한국시간(KST). 장부는 `idem_key` 유니크 + 트랜잭션으로 중복 적립/차감 방지.

## Windows PC에서 바로 실행하기
1. **Node.js 22.13 이상(LTS)** 을 https://nodejs.org 에서 설치합니다. (명령 프롬프트에서 `node -v` 로 확인)
2. ZIP을 원하는 폴더에 풀고 **`start-windows.bat`** 을 더블클릭합니다. 처음 한 번은 패키지 설치와 샘플 데이터 생성이 자동으로 진행됩니다.
3. 브라우저에서 **http://localhost:3000** 을 엽니다.
4. 샘플 로그인: `mom@sample.test` / `dad@sample.test` / `grandma@sample.test`, 비밀번호 `sample1234` (개발용 가짜 계정). 새 가족을 만들려면 `data` 폴더를 지우고 다시 실행하세요.
- 수동 실행: 명령 프롬프트(또는 PowerShell)에서 `npm install` → `npm run seed` → `npm start`.
- 같은 Wi-Fi의 iPad·휴대폰에서 열려면 PC의 IP(`ipconfig`)로 `http://PC주소:3000` 에 접속하고 Windows 방화벽에서 Node.js 허용이 필요합니다. 다만 **휴대폰 푸시와 홈 화면 앱 설치는 HTTPS 주소에서만** 동작하므로, 이 방식은 화면·기능 확인용입니다.

## 실행
```bash
npm install
npm run seed      # (선택) 개발용 샘플 가족 생성: mom@sample.test 등, 비밀번호 sample1234
npm start         # http://localhost:3000
npm test          # 서버 통합 테스트 24개
npm run test:ui   # 브라우저 E2E (Playwright 필요, 스크린샷은 SHOTS_DIR)
```
거실 iPad: 로그인 화면에서 "거실 공용 기기" 체크 후 로그인 → 공유 → 홈 화면에 추가.

## 활동(타이머) · 다음 활동 · 내일 준비물 · 가족 활동 (9~12)
> 화면에서는 ‘타이머’를 **활동**이라고 부릅니다. 기본 활동: 식사하기·TV 보기·게임하기(핸드폰)·양치하기(5분)·숙제하기·책 읽기·씻기(20분), 나머지는 30분. 가족 탭 → ‘활동 설정’에서 이름·시간을 바꿉니다. 아이별 그림은 `public/assets/act/{종류}-{yuel|yuha}.webp` (그림이 없는 조합은 이모지), 엄마·아빠의 ‘일하는 중/집에 가는 중’ 방 그림은 `public/assets/chars/{mom|dad}-{work|car}.webp` 입니다.
- **집 안 표시**: 활동을 시작하면 그 아이 방의 캐릭터가 활동 그림으로 바뀌고, 방에 남은 시간·지난 시간·진행 막대가 1초마다 갱신됩니다. 활동이 끝나면 "⏰ 끝났어요"가 나오고, 확인하거나 새 활동을 시작하면 원래 모습으로 돌아옵니다.
- **저금통 그림**: 돼지 저금통·동전·지폐 그림은 `public/assets/money/` (c100·c500·b1000·b5000·b10000·b50000·piggy). 금액 버튼은 100·500·1,000·5,000·10,000·50,000원입니다.
- **이모지 그림**: `public/assets/emoji/` 의 그림 96장(시트에서 잘라 낸 것)이 `public/js/emo.js` 로 화면의 이모지를 자동 교체합니다. 그림이 없는 이모지는 그대로 이모지로 남고, ✔ 는 흰 글자로 쓰여서 교체하지 않습니다. 그림을 바꾸려면 같은 이름의 webp 파일을 덮어쓰세요.
- **앱 아이콘**: `public/icons/` 의 icon-192·512·maskable-512·apple-touch-icon·favicon-48 (가족 그림 + 분홍·보라 배경). 홈 화면에 이미 추가한 앱은 아이콘이 바로 안 바뀔 수 있어, 삭제 후 다시 추가해야 합니다.
- **가족 얼굴 그림**: `public/assets/chars/face-{gma,mom,dad,yuel,yuha}.webp` 이 프로필 기본 얼굴입니다(올린 사진이 있으면 사진 우선, 직접 고른 이모지가 있으면 그것 우선). 유엘·유하는 가족 탭에 나온 순서(첫째·둘째)로 연결됩니다.
- **도장 애니메이션**: `public/assets/stamp-tool.webp` 도장이 위에서 내려와 "쾅!" 하고 찍히며 화면이 살짝 흔들리고 도장 자국이 남습니다(`playStamp`). 승인되는 순간 서버가 모든 공용 기기(거실 iPad·아이 휴대폰)에 신호를 보내 어느 화면에서든 재생됩니다. 움직임 줄이기 설정을 켜면 자국만 보여 줍니다..
- **도장 요청 흐름**: 루틴을 다 해도 어른에게 바로 알리지 않습니다. 아이 캐릭터가 걸어서 도장 방(확인방)에 오면 방에 `✋ 도장 요청` 버튼이 나타나고(오늘 루틴 화면에도 같은 버튼), 그걸 눌렀을 때 어른 모두에게 팝업·푸시가 갑니다. 도장을 받으면 그 아이는 5초 동안 두 팔을 번쩍 든 모습(`public/assets/chars/yuel-cheer.webp`, `yuha-cheer.webp`)으로 바뀌고, 끝나면 자기 방으로 걸어서 돌아갑니다. 집 안 캐릭터는 한 번 누르면 이동 선택, 빠르게 두 번 누르면 그 아이 화면(루틴·활동·저금통 허브)입니다.
- **활동 시간 = 하루 총 시간**: 활동에 정해 둔 시간(예: 게임 30분)은 하루에 쓸 수 있는 총 시간입니다. 나눠서 해도 되고, **⏸ 일시 중단**하면 남은 시간(예: 18분)이 화면·집 안·아이 카드에 표시되며 시간이 멈춥니다. **▶ 이어서 하기**로 그 시간부터 다시 세고, **⏹ 그만하기**를 해도 남은 시간은 오늘 다시 쓸 수 있습니다. 다 쓰면 "오늘은 다 했어요"가 되고 자정에 새로 시작합니다(어른이 시간을 직접 정해 시작하거나 +5분 등으로 늘릴 수 있어요). 예전 DB는 열 때 자동으로 새 모양으로 옮겨집니다.
- **용돈 받으면 저금통에 쏙**: 용돈·도장판 보상·미션 보상이 들어오면, 그 아이 폰(어느 화면에서든)과 거실 기기에 "저금통에 쏙!" 모션이 나옵니다(형제 폰에는 가지 않아요, 거실 기기에서는 금액을 가려요).
- **누른 그대로 넣고 꺼내기**: 아이가 `돈 넣었어요`·`돈 꺼내기`에서 누른 지폐·동전이 그대로 저장돼(버튼에 ×2 표시), 어른이 확인·지급하면 그 아이 폰에 그 모양 그대로(500원 2번 → 500원 동전 2개) 저금통에 들어가거나 저금통에서 나옵니다. 금액을 직접 쓰거나 어른이 넣은 돈은 금액을 지폐·동전으로 나눠 보여 줍니다.
- **집 안을 돌아다니는 고양이(다이아·크리스탈)와 강아지 귀요미**: 집 그림 안에서 두 마리가 층 바닥을 걷고, 앉고·자고·털을 핥고, 기둥 통로에서는 폴짝 뛰어 다른 층으로 오갑니다. 같은 층에서 마주치면 약 1분에 한 번쯤 마주 보고 장난을 쳐요(고양이 두 마리가 코 비비기·앞발 톡톡·인사·뒹굴기·달리기·살금살금 중 같은 동작 하나로, 귀요미는 장난에 끼지 않아요). 누르면 애교(하트)를 부려요(사람을 골라 이동시키는 중에는 반응하지 않아요). 그림은 `public/assets/cats/`(고양이)·`public/assets/dog/`(강아지), 움직임은 `public/js/views/cats.js`. 가족 탭에서 `집 그림 안에 루비 보이기`·`크리스탈 보이기`·`연이 보이기`로 세 마리를 각각 끌 수 있습니다(장난은 고양이 두 마리끼리만, 사람보다 앞에 그려져요). 위치는 기기마다 따로(서버와 맞추지 않음) 돌아다닙니다. 원본 키트(`moving-cats-kit.zip`)는 `upload` 브랜치의 `cat-upload/` 에만 있습니다.
- **반려동물 주인 · 간식주기 · 산책하기**: 다이아(갈색 고양이)의 주인은 첫째 아이(유엘), 귀요미(강아지)의 주인은 둘째 아이(유하)라서, 움직일 때 절반쯤은 주인이 있는 방 쪽으로 가요(`OWNER_PULL`). 고양이 두 마리가 장난칠 때는 두 마리 사이를 고양이 한 마리 폭의 1/4만 띄워요(`PLAY_GAP_RATIO`). **아이 본인 폰**의 홈 화면, 집 그림 바로 아래에 자기 몫의 `🍪 간식`·`🌳 산책` 버튼 두 개가 있어요(어른 폰·거실 기기에는 없고, 서버도 아이 폰이 아니면 거절해요). 간식주기는 아이 방에서 쿠키가 날아가 그 아이의 동물이 제자리에서 폴짝 뛰고, 산책하기는 아이와 동물이 현관으로 나와 정원을 15초 동안 함께 돈 뒤 방으로 돌아와요. 누른 기기뿐 아니라 거실 iPad·가족 폰 모두에서 같은 장면이 보이도록 서버(`POST /api/pets/act`)가 모든 화면에 알려 줘요. 가족 설정에서 동물 보이기를 끈 동물은 나오지 않아요.
- **화면 배열 바꾸기(어른)**: 홈 화면의 카드·패널(부모님 상태, 아이 카드, 일정·한마디·알림장·챙길 것·가족 활동)과 하단 메뉴, 가족·도장판 같은 화면의 칸들을 **손가락으로 꾹 누르면** 배열 바꾸기 상태가 되고, 끌어서 순서를 바꿉니다(큰 덩어리는 왼쪽 위 `⠿` 손잡이를 끌기). 바꾼 순서는 서버에 저장되어 거실 iPad·가족 휴대폰 모두에 같게 보입니다. 거실 공용 기기는 어른 확인 후에 바꿀 수 있고, 아이 전용 폰에서는 바꿀 수 없어요. 위쪽 `처음 배열로`로 되돌립니다.
- **저금통 기록 지우기(어른)**: 저금통 화면의 기록마다 `🗑 지우기`, 그리고 `이 달 기록 모두 지우기`가 있습니다(어른만, 공용 기기는 어른 확인). 지운 기록은 화면·잔액·월 합계에서 빠지고 뒤 기록의 잔액이 다시 계산됩니다. 도장판 보상 기록은 도장 개수와 묶여 있어 지울 수 없고(도장 기록 정정으로), 지우면 잔액이 모자라게 되는 경우도 막습니다. DB에는 '지움' 표시로 남겨 두어 복구할 수 있어요.
- **아이 폰에서도 우리집 대시보드**: 연결된 아이 폰의 맨 왼쪽 탭 `우리집`에서 집 그림·가족 캐릭터·아이 카드·일정을 볼 수 있습니다. 걷기는 **자기 캐릭터만** 움직일 수 있고(서버도 막음), 어른 상태 바꾸기·알림장·형제 화면은 열리지 않습니다. `내 화면` 탭이 예전 아이 전용 화면입니다.
- **활동 알림이 잠금 화면에도**: `5분 남았어요`·`시간이 끝났어요`가 앱이 열려 있을 땐 팝업으로, 닫혀 있거나 화면이 잠겨 있으면 푸시로 그 활동을 하는 아이의 폰과 거실 기기에 갑니다(형제·어른 폰에는 가지 않아요). 아이 폰에서 `내 설정`의 `알림 받기`를 켜 두어야 합니다.
- **말로 보내기(글을 아직 못 쓰는 아이)**: 아이가 `가족에게 말하기`에서 `직접 쓰기` 옆 🎤 를 누르고 말하면 글자로 바뀌어 입력칸에 보이고, **마지막 말소리 뒤 5초 동안 조용하면 자동으로 전송**됩니다(말을 이어 하면 5초를 다시 세요). 듣는 중에 ⏹ 를 누르면 바로 보내고, 말이 없으면 아무것도 보내지 않습니다. 브라우저의 음성 인식(`SpeechRecognition`)을 쓰는데 **안드로이드 크롬에서는 잘 되고, iPhone의 홈 화면 앱(PWA)에서는 막혀 있을 수 있어요**(그때는 마이크 버튼이 보이지 않아요). 처음 쓸 때 마이크 허용이 필요합니다.
- **빠른 시작과 고정 하단 메뉴**: 서비스 워커가 앱 파일을 폰에 통째로 저장해 두고(서버가 정한 빌드 번호가 바뀌면 새 묶음을 모두 받은 뒤 한꺼번에 교체) 바로 열고, 지난번에 받은 가족 정보·홈 화면을 먼저 그린 뒤 서버 내용으로 바꿉니다(서버가 느려도 '불러오는 중'에 오래 머물지 않아요). 하단 메뉴는 화면에 고정되고 가운데 내용만 스크롤됩니다. 첫 탭 이름은 `우리집`.
- **전체 리셋(어른)**: 가족 탭 맨 아래 `🧹 전체 리셋`. 확인 글자 `리셋`을 입력하면 도장·저금통·알림장·메시지·알림·타이머·준비물·일정·가족 활동 선택 기록을 모두 지웁니다(되돌릴 수 없어요). 루틴·가족 구성·얼굴 사진·활동 종류·화면 배열 같은 설정·로그인된 기기는 그대로 남습니다.
- **아이가 활동 시간 줄이기**: 활동을 고른 뒤 `− 10분`/`+ 10분`으로 어른이 정한 시간에서 10분 단위로 줄일 수 있고, 최대 +30분까지 늘릴 수 있습니다(예: 30분 → 60분까지).
- **성경말씀 루틴**: 할일 `빠른 추가`에 `성경말씀읽기`(성경책 그림 아이콘)이 있습니다.
- **아이 폰 연결(전용 로그인)**: 가족 탭 → 아이 옆 `📱 폰 연결` → 10분짜리 일회용 6자리 코드 → 아이 폰에서 앱 주소 → 로그인 화면의 `아이 폰 연결`에 입력. 그 폰은 그 아이 한 명 전용이 되어 엄마 계정이 폰에 남지 않고, 형제의 저금통·메시지, 어른 승인·정정·연장은 서버가 막습니다. 폰을 잃어버리면 같은 창에서 `연결 해제`. 아이 폰에서도 `내 설정`에서 알림을 켜면 도장·답장 알림이 잠금화면에 짧은 문구로 옵니다(iPhone은 홈 화면에 추가한 앱에서만). 거실 iPad는 기존 `거실 공용 기기` 방식을 그대로 씁니다.
- **집 안 걷기(마이오피스 방식)**: 홈의 집 그림에서 **캐릭터를 눌러 선택**(은은한 빛)한 다음, **가고 싶은 칸을 누르면** 그곳으로 걸어갑니다. 누른 칸에는 점선 타원이 표시되고, 선택이 없을 때 방을 누르면 예전처럼 그 화면으로 이동합니다. 다른 사람이 서 있는 칸 한가운데를 눌러도 목적지로 인식합니다(선택된 사람을 다시 누르면 해제). `🏠 내 방으로`는 자기 방으로 돌아오고, `화면 열기`/`상태 바꾸기`는 그 사람 화면을 엽니다. 칸은 3×3 격자(거실 3칸 / 유엘·유하·확인방 / 할머니·엄마·아빠방)이고, **이동은 층 바닥선과 기둥 통로로만** 합니다(`public/js/views/walkers.js` 의 FLOOR_Y·PILLAR_X, 벽을 가로지르지 않음). 걷는 그림은 `public/assets/walk/{gma,dad,yuel,yuha,mom}.webp`(12프레임, 왼쪽은 좌우 반전)입니다. 현재 칸은 서버에 저장되어 모든 기기에서 같은 위치로 걸어가 보이고, 자기 방에 있을 때만 활동·일하는 중·자동차 그림이 나옵니다. 움직임 줄이기 설정을 켜면 걷는 모션 없이 바로 이동합니다.
- **어른 삭제**: 가족 탭 → 어른 옆 `🗑 삭제` (부모 권한 어른만, 본인은 불가). 로그인·알림 구독이 정리되고 그 어른에게 온 대기 요청은 취소됩니다.
- **타이머** (`server/services/timers.js`): 종료 시각(`ends_at`) 기준으로 남은 시간을 계산하므로 화면 이동·새로고침·잠금 해제 후에도 정확합니다. 서버가 1초마다 정리하며 5분 전 예고(설정 5분 이하는 생략)와 종료를 **정확히 한 번씩** 발생시키고(`warn_sent_for`/`end_sent_for`), 연장하면 새 종료 시각 기준으로 다시 계산합니다. 이미 지난 예고는 다시 띄우지 않고, 팝업의 [알겠어요]는 시간·루틴에 아무 영향이 없습니다. 아이별로 한 번에 하나, 진행 중 다른 활동은 확인 후 교체합니다.
- **알림 경로**: 앱이 열린 거실 iPad는 SSE 이벤트로 팝업 + 부드러운 알람(WebAudio, 가족 설정에서 끄기 가능). 앱이 닫혔거나 잠긴 경우는 **거실 기기로 등록된 푸시 구독**으로 전달합니다 — iPad에서 가족 탭 → 🔑 어른 확인 → 알림 허용. 잠금화면 문구는 "유하 · TV 보기 5분 남았어요" 수준입니다.
- **다음 활동**: 타이머 시작 시 어른이 오늘 미완료 루틴 또는 직접 입력을 고르면 아이 카드·예고·종료 팝업에 "지금 → 다음" 카드와 문구가 나옵니다. 타이머 종료/확인은 루틴 체크나 도장 요청을 만들지 않습니다.
- **내일 준비물** (`supplies.js`): 알림장 글 또는 직접 등록, 여러 개·여러 아이, 아이별 체크, 같은 글의 같은 준비물은 기존 항목 표시, KST 자정이 지나면 오늘로 이동. 루틴·도장 계산과 별개입니다.
- **이번 주 가족 활동** (`famact.js`): 아이별 선택, 어른이 날짜·시간 확정. (주, 후보)당 일정은 항상 1건이라 버튼을 여러 번 눌러도 중복되지 않고 변경은 같은 일정을 갱신합니다.

## 가족 기기(iPad·휴대폰)가 함께 접속할 주소 만들기
**방법 A. 집 PC로 잠깐 써 보기 (무료, 계정 불필요)** — PC가 켜져 있는 동안만 동작하고, 주소는 켤 때마다 바뀝니다.
1. 앱을 실행해 둔 상태(`start-windows.bat`)에서, 다른 명령 프롬프트 창에 `winget install Cloudflare.cloudflared` 로 설치합니다.
2. `cloudflared tunnel --url http://localhost:3000` 을 실행하면 `https://무작위이름.trycloudflare.com` 주소가 나옵니다.
3. 이 주소를 iPad·가족 휴대폰 Safari에서 엽니다. (HTTPS라 홈 화면 추가와 푸시도 가능)

**방법 B. Fly.io에 올려 계속 쓰기 (가족용 고정 주소, 소액 과금 가능)**
1. https://fly.io 가입 후 `flyctl` 설치, `fly auth login`.
2. `fly.toml` 의 `app = "lovefamily"` 를 원하는 고유한 이름(소문자·숫자·하이픈만)으로 바꿉니다. 이미 누가 쓰는 이름이면 다른 이름을 쓰세요.
3. `fly launch --no-deploy --copy-config` → `fly volumes create lovefamily_data --size 1 --region nrt`
4. 푸시를 쓰려면 `npm run vapid` 로 키를 만들고 `fly secrets set VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:내메일`
5. `fly deploy` → 주소는 `https://앱이름.fly.dev`.
6. 접속 후 **새 가족 만들기**로 시작하고, 어른들은 가족 코드/초대 링크로 참여합니다. 거실 iPad는 로그인 때 "거실 공용 기기"를 체크하세요.
※ SQLite를 쓰므로 서버는 **한 대만** 유지하세요(`fly scale count 1`). 데이터 백업은 `fly ssh sftp` 등으로 `/data` 를 받아 두세요.

## Fly.io 자동 배포 (GitHub 푸시 → 배포)
`.github/workflows/fly-deploy.yml` 이 푸시할 때마다 Fly 로 배포합니다. 처음에 한 번만 아래를 해 주세요.
1. Fly 토큰 만들기: https://fly.io/dashboard → 왼쪽/위쪽 **Tokens**(또는 Account → Access Tokens)에서 앱 `lovefamily` 용 **Deploy token** 을 만들고 복사합니다. (명령줄이면 `fly tokens create deploy -a lovefamily`)
2. GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 이름 `FLY_API_TOKEN`, 값 = 복사한 토큰.
3. 저장소 **Actions** 탭 → **Fly Deploy** → **Run workflow** 로 첫 배포를 실행합니다. 이후에는 푸시하면 자동으로 배포돼요.
토큰은 비밀값입니다. 채팅·코드에 붙여 넣지 마세요.

## 환경변수 (비밀값은 코드에 없음)
| 이름 | 설명 |
|---|---|
| `PORT`, `HOST` | 기본 3000 / 0.0.0.0 |
| `DATA_DIR` | DB·사진 위치(영구 볼륨에 두세요) |
| `COOKIE_SECURE=1` | HTTPS 뒤에서 쿠키 Secure (프록시가 `X-Forwarded-Proto: https`를 주면 자동) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | 푸시. `npm run vapid`로 생성 |

## 배포·푸시 설정
1. HTTPS가 필요합니다(푸시·홈 화면 앱 조건). Docker(`Dockerfile`)로 Fly.io/Render/집 서버 등에 올리고 `/data`에 볼륨을 연결하세요.
2. `npm run vapid` 결과를 환경변수에 설정하고 재시작.
3. 각자 iPhone에서 Safari로 접속 → 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 열기 → 가족 탭 → **알림 허용**. (iOS 16.4 이상, 홈 화면 앱에서만 푸시 가능)
4. 잠금화면에는 "유엘 · 도장 확인 요청"처럼 이름/종류만 표시되고, 본문·사진·금액은 앱에서만 보입니다.
5. 백업: `DATA_DIR` 폴더(SQLite + photos)를 주기적으로 복사하세요.
